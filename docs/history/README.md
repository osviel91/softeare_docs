# Documentation History

These documents are historical plans and reports, not current product
specification. They are retained when they explain delivered work, tradeoffs,
or verification useful to future maintainers.

## Classification

- **CURRENT**: root `README.md`, `CONTEXT.md`, `ARCHITECTURE.md`, and
  `docs/architecture-baseline.md` describe today's product and contracts.
- **HISTORICAL**: files under this directory record past plans, checkpoints, and
  deployment evidence. Their phase language is intentionally historical.
- **MIXED**: `ARCHITECTURE.md` contains current architecture followed by a
  retained ADR table. Current sections take precedence over old rationale.
- **OBSOLETE**: redundant root status summaries were removed; no standalone
  obsolete document is retained here.
